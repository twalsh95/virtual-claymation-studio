Studio Layout Mockup

Layout A, department tabs, is the chosen direction. Try the toolbar sizes: the Minimize button at the right end (or H) shrinks the toolbar to just its tabs, then hides it, then brings it back. Click around, and try the keys: number keys 1 to 4 switch tabs, letter keys pick tools, and ? shows every key. The 3D scene is a stand-in drawing; the shot panel and shot strip on the right and bottom are the same in both layouts.

Draft key list

Every control gets a key. Keys that only make sense in one tab (like the camera moves) only work in that tab, so the same letter can be reused. This is a draft to settle together. A game controller would later trigger the same actions (for example, bumpers switch tabs, A captures).
